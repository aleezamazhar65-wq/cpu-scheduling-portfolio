# CPU Scheduling Concepts

## Overview

This portfolio project documents my learning about CPU scheduling and operating systems as part of my Software Engineering studies at Carleton University.

The focus is on understanding how operating systems decide which process receives CPU time, how scheduling policies differ, and how their decisions affect system performance.

## Concepts Studied

- First-Come, First-Served (FCFS)
- Round Robin (RR)
- Shortest Remaining Time First (SRTF)

## Technical Topics

- Process lifecycle and process states
- Ready queues and waiting processes
- CPU bursts and I/O waits
- Context-switch overhead
- Scheduling timelines and performance metrics

## Technologies

- C
- Linux / WSL2
- Make
- Python for testing and supporting tools

## Learning Goals

- Understand the trade-offs between scheduling algorithms.
- Practise debugging and structured problem-solving.
- Explain how scheduling affects waiting time, response time, turnaround time, and CPU utilization.
